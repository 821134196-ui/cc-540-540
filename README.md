# 家长会预约系统

班主任为各班发布家长会预约窗口；监护人选择**线下 / 视频**会谈并填写讨论事项；
教师确认后生成时段，会谈结束记录结论与后续待办（**负责人 + 期限**）。
涉及学生的资料只对**本班任课教师**和**当前有效监护人**开放，所有访问（含拒绝）记入 SQLite。

零第三方依赖，仅使用 Python 3.10+ 标准库 + SQLite。

## 一条命令启动

```bash
./run.sh            # 默认 http://127.0.0.1:8000
./run.sh 8011       # 指定端口
./run.sh 8000 --reset   # 清空并重建演示数据
```

等价于 `python3 -m app [--port 8000] [--reset]`。首次启动自动初始化数据库、
写入演示数据（`data/app.db`）与虚构附件（`data/attachments/`）。

## 关键业务规则

- **时段冲突**：同一教师时间重叠的时段拒绝创建；首尾相接允许。
- **抢占**：同一时段同时只能有一份有效预约（`pending` 也占位），
  数据库部分唯一索引 + 应用层预检查双重兜底。
- **一人一约**：一个学生同一轮家长会只能保留一份有效预约；
  改期申请期间旧预约仍占名额，通过后原子移动、旧时段释放。
- **多监护人**：任一监护人均可预约/取消；改期仅限预约发起人；
  授权撤销后旧账号立即失去预约、视频、纪要、附件全部权限。
- **教师请假**：重叠时段内的有效预约进入 `teacher_leave` 改期队列并通知监护人，
  空闲时段取消；监护人可对未被占用的可选时段自助重选。
- **视频**：模拟链接可失效；教师轮换后旧链接失效、新链接可用并通知。
- **纪要**：只有本班任课教师可写（监护人角色写入直接拒绝并记日志）；
  锁定后不可改；监护人只读；外班教师、其他家庭、被撤销账号一律拒绝并审计。
- **后续待办**：必须含内容、负责人、期限；负责人或本班教师可标记完成；逾期可提醒。

## JSON API（除页面外可用）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/slots?round_id=1[&view=teacher]` | 家长只取可约时段；教师日历需本班权限 |
| GET/POST | `/api/bookings` | 我的预约 / 创建预约（冲突、一份规则返回 400） |
| GET | `/api/reschedule/queue?class_id=1` | 改期队列（教师） |
| POST | `/api/leave` | 登记教师请假 `{teacher_id,start_at,end_at,reason}` |
| GET/POST | `/api/video/{booking_id}[/rotate]` | 进入会议（失效返回 `link_expired`）/ 轮换 |
| GET | `/api/minutes/{id}` | 查看纪要+待办（按身份鉴权） |
| GET | `/api/overdue` | 逾期未完成的后续事项（教师） |

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖：

1. **时段冲突**（重叠拒绝、相邻允许、同时段抢占、窗口关闭、确认后锁定）；
2. **多监护人规则**（一轮一份、不同监护人抢占、取消释放、改期发起人与名额保持）；
3. **授权撤销**（列表/单份纪要/预约/视频/附件全部失效、拒绝落审计、其他监护人不受影响）；
4. **纪要权限**（家长不能写结论、外班教师不可见、锁定不可改、待办负责人与逾期）；
5. 端到端：请假改期队列与自助重选、视频失效轮换、超时记录、逾期通知、HTTP 页面/API。

## 数据与隐私说明

- 所有数据保存在本地 SQLite（`data/app.db`），附件为本地纯文本虚构样例；
  视频与通知均为模拟适配器，不会发起真实呼叫或外发消息。
- `access_logs` 记录每次登录、预约、纪要/附件/视频访问的允许与拒绝结果，
  教师端“访问记录”页可查。
