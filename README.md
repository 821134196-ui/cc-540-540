# 家长会预约系统

班主任发布家长会预约窗口，家长选择**线下或视频**会谈并填写讨论事项；教师确认后
生成时段，会谈结束时记录双方约定的后续事项。涉及学生的资料只对**本班任课教师**
和**在权监护人**开放。

仅使用 Python 标准库 + SQLite，无外部依赖。

## 启动

```bash
./run.sh              # 首次自动写入演示数据（含教师请假样例）并启动
./run.sh --reset      # 重建演示数据后启动
PORT=8080 ./run.sh    # 指定端口
```

## 功能与场景对照

| 需求场景 | 实现 |
|---|---|
| 发布窗口、线下/视频、讨论事项 | 轮次 `open_from/open_until`；预约带 `mode/topics` |
| 教师确认后生成时段 | `confirm` 可分配/确认时段，日历按教师与时间排列 |
| 结束时记录后续事项 | 纪要 + 待办，**每条待办强制填写负责人与期限**；逾期标红，可勾选完成 |
| 资料仅本班教师 + 监护人开放 | `teachers(class_id)` / `guardianships.active` 双重判定，纪要、附件、视频入口统一鉴权 |
| 家长临时改期 | 进入**改期队列**（pending/approved/rejected），可先选新意向时段 |
| 多监护人抢同一时段 | 部分唯一索引 + `BEGIN IMMEDIATE`，并发下只有一份成功 |
| 一个学生同一轮一份有效预约 | 部分唯一索引 `idx_student_round_active` 兜底 |
| 教师请假 | 未来时段整段取消，受影响预约自动入改期队列、视频链接作废、模拟通知监护人 |
| 视频链接失效 | 链接可标记失效；双方任一方可刷新，旧链接作废并通知对方（模拟视频适配器） |
| 会谈超时 | 纪要可勾选超时并展示标记 |
| 后续事项未完成 | 待办 open/done，超过期限显示“已逾期未完成” |
| 授权撤销 | 撤销后旧账号立即 403；所有查看尝试写入 `access_logs`（含拒绝） |
| 教师不能以家长身份改结论 | 修改纪要只认“本班任课教师”关系，家长角色一律拒绝 |
| 家长端只展示可选时段与自己的纪要 | `/slots` 仅返回 open 时段；`/bookings` 仅返回在权子女数据 |
| 白 / 校园蓝 / 温和绿、窄屏完整显示时间 | `static/styles.css`，720px 以下单栏且时间不截断 |

## 交付物

```
app/
  db.py          SQLite 建表（含两条关键部分唯一索引）
  adapters.py    模拟视频适配器、通知适配器、本地虚构附件存储
  auth.py        身份/角色/任课/监护判定与访问日志
  services.py    领域服务（预约、冲突、改期、请假、视频、纪要、待办、授权）
  server.py      标准库 HTTP/JSON API + 静态文件
  seed.py        演示数据（含一轮已完成纪要与教师请假样例）
  static/        index.html / styles.css / app.js
data/
  conference.db  SQLite：预约、改期、纪要、待办、访问记录、通知…
  files/         本地虚构附件
run.sh           一条本地命令启动
tests/           时段冲突、多监护人、授权撤销、纪要权限等测试
```

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖：时段并发冲突、多监护人规则（一学生一轮一预约）、家长临时改期、
教师请假入队、授权撤销后旧账号拒绝、纪要读写权限（含教师以家长身份）、
视频链接失效刷新、待办与访问记录。
